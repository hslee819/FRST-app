# TA 학습 앱 HTML

사진 속 앱을 재현한 **기본 버전**과, 기존 화면 디자인을 유지하면서 요청한 기능을 더한 **기능 추가본**을 별도 파일로 관리합니다. 기본 HTML은 그대로 보존합니다.

## 바로 열기

- `basic.html`: 사진을 바탕으로 만든 기본 앱. 리뉴얼 빌드 시 덮어쓰지 않습니다.
- `TA.html`, `renewal.html`: 같은 소스에서 생성하는 동일한 기능 추가본입니다. CSS와 JavaScript를 포함하므로 브라우저에서 직접 열 수 있습니다.
- `src/renewal-base.html`: 기능 추가본의 개발용 HTML. 기존 기본 스타일과 앱 코드를 포함합니다.
- `src/renewal-ui.css`: 문항 사진, 요약·분류, 복습 팝업 등 추가 기능에만 적용하는 스타일입니다.
- `src/review-cards.js`, `src/review-cards.css`: 북마크 기반 복습 카드와 진행 기록을 담당합니다. 기본 앱 스크립트보다 먼저 실행하도록 함께 빌드합니다.

실행할 때 인터넷 연결이나 패키지 설치는 필요하지 않습니다. 기능 추가본과 `basic.html`을 같은 폴더에 두면 앱 안의 버전 링크로 기본 화면을 열 수 있습니다. 수정은 `src/`에서 하고, 빌드로 두 기능 추가본을 함께 갱신합니다.

기능 추가본은 `basic.html`의 헤더, 접이식 메뉴, 본문 배치와 반응형 스타일을 유지하며 브라우저 전체 영역을 사용합니다. 과목·콘텐츠·회차·문항 번호 선택은 기존 배치와 스크롤 방식을 따릅니다. 북마크 복습은 별도 팝업에서 진행합니다. `basic.html`과 개발 원본의 첫 인라인 스타일은 바꾸지 않습니다.

## 개발 명령

Node.js 20 이상이 필요합니다. 저장소 루트에서 아래 명령으로 `app/ta` 폴더에 들어간 뒤 빌드와 미리보기를 실행합니다.

```powershell
cd app/ta
npm.cmd run build
npm.cmd run preview
```

PowerShell에서 `npm.ps1` 실행 정책 오류가 발생할 수 있어 위 예시는 `npm.cmd`를 사용합니다. 일반 셸에서는 `npm run build`, `npm run preview`로 실행해도 됩니다. Node.js만 직접 호출할 수도 있습니다.

이 문서와 작업 지침은 가져온 소스 및 회귀 테스트의 현재 동작에 맞춰 정리했습니다. 수정 작업은 저장소 루트의 [`AGENTS.md`](../../AGENTS.md)에 따라 동기화, 수정, 검증, 커밋, 푸시 순서로 진행합니다.

```text
node tools/build.mjs
node tools/preview.mjs
```

빌드는 `TA.html`과 `renewal.html`을 동일한 내용으로 생성합니다. 기본 버전은 덮어쓰지 않으며, 소스나 필수 자산 검증이 실패하면 기존 출력 파일을 유지합니다.

미리보기 주소:

- 기능 추가본: <http://127.0.0.1:4174/TA.html>
- 동일한 기능 추가본 및 기본 진입 경로: <http://127.0.0.1:4174/renewal.html>
- 기본 버전: <http://127.0.0.1:4174/basic.html>
- 개발 원본: <http://127.0.0.1:4174/src/renewal-base.html>

미리보기 서버는 `Ctrl+C`로 종료합니다. 다른 포트가 필요하면 `PORT` 환경 변수를 지정합니다. 서버는 허용된 앱 자산만 제공합니다.

## 검증

```powershell
npm.cmd test
```

Node.js 기본 테스트 러너로 다음을 확인합니다.

- 기본 HTML 파일을 바꾸지 않고 기능 스타일과 복습 모듈을 기능 추가본에 포함하는지
- 기본 파일 SHA256과 첫 인라인 스타일이 보존되고, 추가 CSS가 기능 영역 안에 한정되는지
- 기존 헤더·접이식 메뉴·본문 구조가 보존되고, 메뉴 열기·닫기와 다섯 메뉴 이동이 동작하는지
- `TA.html`과 `renewal.html`이 함께 갱신되어 동일한 내용을 제공하는지
- 사진 원본 바이트와 기존 콘텐츠가 빌드 과정에서 보존되는지
- 복습 카드 모듈과 스타일이 포함되고 앱 초기화 전에 실행되는지
- UI 스타일 링크가 누락·중복되거나 JavaScript 문법이 잘못된 경우, 필요한 사진이 없는 경우 기존 결과 파일을 덮어쓰지 않는지
- 미리보기 서버의 파일 접근 제한, 기본 경로 이동, HEAD 요청 및 오류 응답
- 리뉴얼 화면의 원본 데이터·TA/SA 상태 보존과 문항 선택·질문 흐름
- 전체 선택 목록에 모든 회차와 문항 번호가 포함되고, 마지막 문항을 선택해도 작성 중인 질문이 유지되는지
- 복습 팝업의 첫 진입 자동 표시, 닫기·다시 열기, 진행 보존, 원문 이동, 외부 문항 링크의 팝업 미표시

빌드·미리보기 검사와 간소화한 DOM 환경의 흐름 검사를 사용합니다. 자동 검사는 실제 브라우저의 배치·글자 크기·렌더링이나 네이티브 대화상자 동작을 검증하지 않습니다. 화면을 바꿀 때는 기본 버전과 비교하며 넓은 화면과 좁은 화면에서 별도로 확인합니다.

## 기능 추가 범위

일반 실행 시 북마크한 질문이 있으면 **북마크 복습 팝업이 한 번 자동으로** 열립니다. 닫으면 기존 문항 선택 화면을 그대로 사용할 수 있으며, 문항 검색과 나의 질문들의 **북마크 복습** 버튼으로 다시 열 수 있습니다. 기존 접이식 메뉴에서 문항 검색·문항 질문·TA Meet·SA Meet·나의 질문들로 이동합니다. 문항·질문·답변과 북마크, 답변 평가, TA/SA 상태를 보존하면서 다음 기능을 더합니다.

- 문항 링크나 답변에서 질문으로 이동하면 해당 문항 정보가 미리 채워집니다.
- 문항 사진은 한 장을 먼저 보여주고, 다른 학생 질문은 **짧은 질문 요약·해시태그·답변 요약**으로 표시합니다. 펼치거나 상세보기를 누르면 기존 전문을 읽을 수 있습니다.
- **문항 풀이·개념**과 **학습 상담·기타**를 나누어 필요한 질문을 골라봅니다.
- 북마크한 질문에서 해당 문항 정보가 채워진 질문 화면으로 이동할 수 있습니다.
- 북마크한 질문은 복습 팝업에서 한 장씩 뒤집어 답변을 확인하고 **오늘 복습 완료**를 기록할 수 있습니다. 닫았다 다시 열어도 진행 기록이 유지되며, 이전·다음 카드와 다시 복습도 지원합니다. 외부 문항 링크로 들어올 때는 복습 팝업을 자동으로 열지 않아 질문 흐름을 유지합니다.

요약과 해시태그는 기존 질문·답변을 빠르게 탐색하기 위한 표시이며, 원문은 그대로 보존합니다. 문항·답변·TA 데이터와 원본의 이용권·상담 제약은 그대로 사용합니다.

**문항 사진**에는 선택한 과목·콘텐츠·회차·번호에 해당하는 실제 문제 원문 사진 한 장을 표시합니다. 해설지 사진이나 일반 풀이 첨부 이미지는 문항 원문으로 대체하지 않습니다. 제공 사진에서는 완전한 문제 원문을 확보하지 못했으므로, 처음에는 빈 사진 자리가 표시됩니다. 이 영역의 사진 등록 버튼으로 해당 문항의 원문 사진을 넣을 수 있습니다. 등록 사진은 `ta-original-problem-photos-v1`에 문항별로 저장됩니다. 제공된 `KakaoTalk_20261106_151959657_14.jpg`는 해설 화면이므로 문항 사진 영역에 사용하지 않습니다.

## 다른 앱에서 문항 열기

기능 추가본 주소에 `subject`, `content`, `round`, `number`를 전달하면 해당 문항 정보가 채워진 질문 화면이 열립니다. `view`는 선택 사항이며 `question`이 기본값입니다. `answers`를 지정하면 해당 문항의 다른 학생 질문 목록으로 이동합니다.

```text
http://127.0.0.1:4174/renewal.html?subject=국어&content=서바이벌프로&round=8&number=2&view=answers
```

다른 앱에서 주소를 만들 때는 `URLSearchParams`로 한글과 기호를 인코딩합니다. 실제 서비스에 배포한다면 위의 로컬 주소를 해당 서비스 주소로 바꿉니다.

```js
const query = new URLSearchParams({
  subject: '국어', content: '서바이벌프로', round: '8', number: '2', view: 'question'
});
const url = `http://127.0.0.1:4174/renewal.html?${query}`;
```

과목·콘텐츠·회차·번호는 선택 화면의 허용값으로 검증합니다. 필수값이 빠졌거나 유효하지 않은 주소는 기본 ‘문항 검색’ 화면으로 돌아갑니다. 링크 이동을 지원하며 다른 앱의 계정이나 데이터 서버에 자동 연결되지는 않습니다.

회차는 서바이벌 `16·17·18회`, 월례고사 `9·10·11회`, 엑셀러레이터 `1–18회 및 27·28·29회`, 그 외 기존 콘텐츠 `1–18회`를 지원합니다. 엑셀러레이터 27–29회는 eBook에서 같은 문항의 질문 폼으로 연결하기 위해 추가했으며, 문항 변경 화면에서도 선택할 수 있습니다. 과목과 문항 수 제한은 기존과 같습니다. 국어·영어는 1–45번, 수학은 1–30번, 물리학Ⅱ·사회문화는 1–20번이며 한국사는 지원하지 않습니다. 신규 답변이나 TA 데이터는 추가하지 않습니다.

## 구현 범위

두 앱은 사진 속 화면과 상호작용을 재현한 프런트엔드 프로토타입입니다. 기본 버전의 콘텐츠와 예시 데이터를 리뉴얼 버전에서도 사용합니다. 실제 TA에게 질문을 보내거나 상담을 예약하는 서버는 연결되어 있지 않습니다.

질문과 북마크, 답변 평가 등 기본 앱에서 저장하는 항목은 현재 브라우저의 로컬 저장소를 사용합니다. 복습 카드는 앞면의 질문 요약·해시태그에서 답을 떠올린 뒤 뒤집어 답변 요약을 확인하고, 이전·다음 카드로 이동하거나 오늘 복습 완료를 기록할 수 있습니다. 진행 상태는 기본 앱 기록을 바꾸지 않도록 별도 `ta-review-cards-v1` 키에 저장합니다. 브라우저·프로필·접속 주소를 바꾸면 저장 내용이 공유되지 않으며, 사이트 데이터를 지우면 초기화됩니다. 브라우저 설정으로 로컬 저장소가 차단된 환경에서는 영구 저장이 제한될 수 있습니다.
