# 시대인재 N 화면 재현

제공된 앱 화면 32장(`n/`의 23장과 상위 폴더의 9장)을 기준으로 만든 프런트엔드 프로토타입입니다. 아이패드 화면의 메뉴·문구·배치·색상을 1180×820 기준으로 구성하고, 브라우저 크기에 맞춰 전체 화면을 같은 비율로 축소합니다.

## 실행과 수정

이 저장소의 `app/` 폴더에서 Node.js 20 이상으로 실행합니다. 패키지 설치는 필요하지 않습니다. 저장소 루트에서 실행할 때는 명령의 경로 앞에 `app/`을 붙입니다. 협업 작업은 루트의 `../../AGENTS.md`에 따라 최신 원격 반영·검증·커밋·푸시까지 진행합니다.

```powershell
node n/build.mjs
node n/preview.mjs
node --test n/tests/*.test.mjs
```

- `N.html`: CSS·JavaScript·이미지를 포함한 단일 파일입니다. 빌드 후 브라우저에서 직접 열거나 다른 폴더로 옮겨 사용할 수 있습니다.
- `focus-content.html`: 상위 폴더의 `몰입도.html`에서 빌드한 몰입도 탭 개발용 화면입니다. 단일 `N.html` 안에도 같은 내용이 포함됩니다.
- `grades-content.html`: `reference/sdij_drawer_tobe.html`에서 빌드한 성적 탭 화면입니다. 단일 `N.html` 안에도 포함됩니다.
- <http://127.0.0.1:4176/>: 개발 원본을 표시합니다.
- <http://127.0.0.1:4176/N.html>: 빌드 결과를 표시합니다.
- 미리보기는 `Ctrl+C`로 종료합니다. 다른 포트는 `PORT` 환경 변수로 지정합니다.

`index.html`, `src/*.js`, `src/*.css`에서 수정한 뒤 다시 빌드합니다. `N.html`을 직접 수정하지 않습니다. 빌드는 스크립트 문법과 로드 순서를 확인한 뒤 출력하며, 이미지 원본은 변경하지 않습니다. 미리보기 서버는 지정된 앱 파일과 `assets/*.png`만 제공합니다.

## 구성

- `src/app.js`, `src/base.css`: 공통 화면, 메뉴, 모달과 화면 비율 조정
- `src/my.*`: 홈·MY 영역
- `src/services.*`: Library·상담·학습 지원 화면
- `src/focus.*`, `focus-content.mjs`: 기존 `몰입도.html`을 몰입도 탭 안에 연결하고 공통 헤더와 메뉴가 겹치지 않도록 조정
- `src/grades.css`, `grades-content.mjs`: 성적 원본을 별도 프레임에 연결하고 프로필·콘텐츠 배부도·콘텐츠 서랍장 탭·자동 푸시를 제거, 두 성적 메뉴를 상단으로 배치
- `reference/sdij_drawer_tobe.html`: `C:\Coding\FRST-work\개선 앱 화면`에서 복사한 수정하지 않은 원본 (SHA-256: `9dd035fa6634b870fa2485263010ad466e3b02714f6dd5a523a02b56a3b0adf4`)
- `assets/`: 제공 화면에서 추출한 그림과 가이드 카드
- `.qa/`: 추출 좌표·원본 해시·확인용 자료

## 데이터와 구현 범위

화면에 표시된 이름·날짜·수치·예시 내용을 재현합니다. 실제 계정에 로그인하거나 기관 서버와 연결하지 않습니다. 신청·응답 등 상호작용은 이 브라우저 안의 시연이며, 해당 모달에서 로컬 동작임을 안내합니다. 실제 상담 예약이나 신청 전송은 수행하지 않습니다.

제공 화면에 없는 세부 자료와 결과는 만들어내지 않습니다. 확인할 수 없는 내용은 빈 상태 또는 안내로 표시합니다. 가이드북의 시그니처 카드는 원본 오른쪽이 잘려 있어 제공된 부분만 사용합니다.

몰입도 탭은 상위 폴더의 사진을 반영한 기존 `몰입도.html`의 화면·데이터·기능을 그대로 사용합니다. 나의 학습, 주간·일별 공부 시간, 비교 그래프와 교시별 표, 월간 추이, 기록 추가·관리, CSV 내보내기를 제공합니다. 기존 HTML의 스타일과 스크립트는 별도 프레임 안에 유지하며, N 앱의 제목·메뉴와 겹치는 부분만 조정합니다. 비교 자료와 시간대별 분배의 예시 범위는 기존 화면의 안내를 따릅니다. 탭을 나갔다가 다시 열면 조회 위치는 초기화되며 저장한 학습 기록은 원래 저장 방식을 따릅니다.

My 메뉴의 몰입도 바로 다음에 있는 성적 탭은 리포트 서랍장으로 시작하며, 상단에서 부엉이 분석실로 이동합니다. 콘텐츠 서랍장 탭, 자동 푸시 알림, 이름·관·수능 D-day·콘텐츠 배부도는 제외했습니다. 과목·회차별 성적, 문항별 데이터, 추이 그래프, 원본의 문항·질문 화면 등을 유지합니다. 원본은 시연 데이터이며 실제 성적 조회·질문 전송·앱 간 이동은 연결되어 있지 않습니다. 탭을 다시 열면 원본의 초기 상태로 돌아갑니다. 공통 앱의 1180×820 비율을 유지하고 성적은 헤더 아래 1180×672 공간을 채웁니다. 불필요한 헤더와 하단 메뉴 공간을 줄여 표와 그래프를 추가 축소 없이 표시합니다. 외부 폰트 CDN 없이 시스템 글꼴로 동작합니다.

자동 검사는 메뉴 이동, 원본 몰입도 코드와 자료 보존, 로컬 입력 검증, 저장 실패 처리, 단일 파일 자산 포함 및 미리보기 응답을 확인합니다. Node VM/간소화한 DOM을 사용하므로 실제 브라우저 검증을 대신하지 않습니다.

현재 실제 브라우저의 배치·렌더링 검증은 완료되지 않았습니다. 빌드의 문법 검사는 실제 화면이나 모든 상호작용의 검증을 대신하지 않습니다.
