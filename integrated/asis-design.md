# 시대인재 앱 as-is 디자인 기준

기존 앱 6종(콘텐츠 서랍장 · TA · eBook · 시대인재N 재종 · 부엉이 타이머 · 스케줄러)의 현황 재현 화면(`prototype/*_asis.html`)에서 CSS와 화면을 분석해 공통 규칙을 정리한 문서입니다. 통합 앱 프로토타입(`integrated/sdij_integrated_app.html`)은 이 문서를 기준으로 만듭니다.

- 분석 대상: `sdij_drawer_asis` · `ta_asis` · `ebook_asis` · `jaejong_asis` · `timer_asis` · `scheduler_asis` (2026-11-02 재현본)
- 기준 기기: iPad 가로 1180 × 820, 상태바 30px
- 표기: **공통** = 5개 이상 앱에서 같은 값 / **앱별** = 일부 앱에만 있는 값

---

## 1. 전체 인상

- 흰 배경 + 검정 강조의 모노톤 화면. 유채색은 과목 색과 상태 표시(빨강)에만 씀
- 굵은 제목(700~800)과 회색 비활성 텍스트의 명도 차이로 위계를 만듦
- 구획은 그림자가 아니라 얇은 회색 보더(1px)와 여백으로 나눔
- 버튼과 칩은 둥근 알약형(pill), 카드·박스는 거의 각진 3~6px 모서리

## 3. 서체

- **Pretendard** (CDN `pretendard@v1.3.9 static`), 대체 `-apple-system, "Apple SD Gothic Neo", "Noto Sans KR"`
- eBook 지문만 명조(`"Nanum Myeongjo", "Batang", serif`)
- 자간: 큰 제목 `-0.3px`, 나머지 0

| 역할 | 크기 / 굵기 | 예 |
| --- | --- | --- |
| 화면 제목 · 사용자 이름 | 20px / 800 | "이현서t 님", "문항 검색" |
| 기간 · 보기 전환 큰 토글 | 20~21px / 800 (비활성 `--line2`) | 연간 · 월간 · 주간 |
| 과목 탭 | 16px / 700 (비활성 `--line2`) | 전체 · 국어 · 수학 |
| 모달 제목 | 21px / 800, 가운데 정렬 | 목표 대학 설정 |
| 카드 · 패널 제목 | 13~15px / 700 | 개인 성적 분석 |
| 본문 | 12~13px / 400~500 | 표 · 목록 |
| 보조 · 메타 | 9.5~11.5px | 날짜 · 개수 · 안내문 |
| 큰 숫자 | 23~24px / 800 (타이머 숫자 80~90px / 800) | 원점수 · 표준점수 |

- 재종 앱(시대인재N)만 전체적으로 한 단계 큼 (본문 14~16px, 날짜 40px 이상)

## 4. 레이아웃

### 4.1 화면 골격 (서랍장 · 타이머 · 스케줄러 공통)

```
상태바 30px
헤더 80px    이름 20/800 + 소속 11.5px | D-day · 진행 막대 | 알림 · 설정 원형 버튼
보조 행 32px 과목 탭(왼쪽) + 필터 칩(오른쪽)
본문 박스    좌우 30px 여백, 1px --line2 보더, radius 5px
탭바 70px    상단 1px --line, 아이콘 + 9.5~10px 라벨, 가운데 정렬
```

- 좌우 여백 **30px** 고정, 박스 안쪽 여백 15~16px
- 탭바는 2~3개 아이콘을 가운데에 모으고 간격 76~120px. 활성은 검정 + 700, 비활성 `#aaa`
- eBook만 왼쪽 세로 사이드바(152px, 활성 메뉴 검정 채움)
- 재종 앱은 햄버거 → 왼쪽 검정 사이드 메뉴(`#1d1d1f`, 약 530px)

### 4.2 헤더

- 왼쪽: 이름(20px/800, `t 님` 포함) 아래 소속 `임시관 · 서울대 공학계열` 11.5px
- 가운데: `대학수학능력시험 D-17` (라벨 11px 회색 + 값 14px 굵게), 아래 진행 막대(100×8px, radius 4, 검정 채움) + `68%`
- 오른쪽: 26px 원형 아이콘 버튼(`--bg2` 배경) 알림 · 설정

## 5. 컴포넌트

### 5.1 버튼

| 종류 | 규격 | 예 |
| --- | --- | --- |
| 회색 알약 버튼 | 높이 26~28px, radius 13~14px, 1px `--line2`, 배경 `--bg2`, 12px | 새로 고침 · 오늘 · SDIJ 테이블 |
| 검정 알약 버튼 | 높이 28~36px, radius 14~18px, `#111` 채움 + 흰 글자 700 | 질문하기 → · 일정 추가하기 |
| 둥근 화살표 | 24px 원, 검정 채움(비활성 `#e3e3e3`) | 기간 이전 · 다음 |
| 모달 하단 버튼 | 높이 **68px**, 전폭, 반반 분할 [취소 흰색 · 확인 검정], radius 0 | 목표 대학 설정 · 콘텐츠 리뷰 |
| 원형 컨트롤 | 아이콘 + 아래 라벨 | 타이머 종료하기 · 일시정지 · 다음 |
| 화면 목록 | 검정 알약, 우하단 고정 | 모든 앱 공통 |

### 5.2 탭 · 토글

- **큰 텍스트 토글**: 20px/800, 활성 `#111` · 비활성 `--line2`. 밑줄이나 배경 없이 글자 색만으로 전환 (연간 · 월간 · 주간, 월간 · 주간 · 일간, 문항/성적 같은 화면 내 전환)
- **과목 탭**: 16px/700, 같은 방식
- **칩 필터**: 높이 24~28px, radius 12~14px. 비활성 `#dedee1` 배경 또는 흰 배경 + 보더, 활성 검정 채움 + 흰 글자 (eBook 서바·엑셀·월례, 서랍장 필터)
- 필터 칩 오른쪽에 12px 검정 원 + ▼(펼침) 또는 ✕(선택 해제)

### 5.3 박스 · 카드

- 본문 박스: 1px `--line2`, radius **4~6px**, 흰 배경
- 패널(카드 안 구획): 1px `--line2`, radius 3~4px, 제목 13px/700 + 오른쪽 작은 알약 버튼
- eBook 콘텐츠 카드: `#f3f3f5` 배경, radius 8px, 보더 없음, 상단 과목 점 + 상태 배지, 가운데 표지 이미지
- TA 카드: 흰 배경 + 1px `--line`, hover 시 보더 `#999`

### 5.4 표

- 헤더 행: 회색 글자 500 또는 굵은 글자 700, 하단 2px `--line`
- 행 높이 42~47px, 홀수 행 `--bg2`(리포트 문항표)
- 오답 행은 번호 · 내 답안을 빨강으로
- 답안 번호는 15px 원 안 숫자(①~⑤ 스타일)
- 서랍장 연간 표: 왼쪽 과목 · 유형 · 콘텐츠명 3열 고정(sticky), 주차 열 39px, 현재 주차 머리글 빨강

### 5.5 배지 · 태그

- 상태 배지: 높이 16~18px, radius 2~9px, 작은 글자 9~10px 700 (학습 완료 금색, 문제 해결 파랑, 측정 중 검정)
- 테두리 태그: 1px `--line2` + `#fafafa` 배경 + `#666` 글자 9px (TA 카드)
- 알림 점: 6px 빨강 원

### 5.6 모달 · 팝업

| 종류 | 규격 |
| --- | --- |
| 기본 모달 | 흰 배경, radius 4px, 폭 400~560px. 제목 21px/800 **가운데 정렬** + 아래 1px 구분선(좌우 16px 안쪽). 본문 가운데 정렬. 하단 68px 전폭 버튼 |
| 확인창 | 폭 300~400px, 문장 14px 가운데, 하단 검정 전폭 버튼 |
| 설정 | 오른쪽 사이드 패널(약 380px), 목록형 메뉴 + 토글 |
| 작은 팝업 | 칸 옆에 뜨는 210px 박스, radius 6px, 그림자 `0 8px 24px rgba(0,0,0,.12)`, 알약 버튼 2개 |
| 딤 | `rgba(0,0,0,.55 ~ .7)` |
| 토스트 | 하단 가운데 `rgba(60,60,60,.92)` 알약, 14px 흰 글자 |

### 5.7 그림자

- 드롭다운 · 팝업 메뉴: `0 4px 14px rgba(0,0,0,.06)` ~ `0 6px 24px rgba(0,0,0,.18)`
- 플로팅 버튼(화면 목록): `0 4px 12px rgba(0,0,0,.2)`
- 아이패드 프레임: `0 20px 60px rgba(0,0,0,.25)`
- 카드 · 박스에는 그림자를 쓰지 않음

### 5.8 아이콘

- 선형 SVG, stroke 1.6~2, 색은 글자색을 따름
- 탭바 아이콘 24~26px 채움형(서랍 · 리포트 · 원자 / 타이머 · 히스토리 · 막대)
- 헤더 아이콘 15~16px

## 6. 화면 패턴

- **연간 · 월간 · 주간 보기**: 큰 텍스트 토글 + 검정 화살표 + 기간 제목(20px/800) + 오른쪽 "새로 고침 · 오늘" 회색 알약
- **목록 → 상세**: 상세는 상단 왼쪽 ← 화살표, 가운데 제목, 오른쪽 검정 알약 액션 (TA 검색 결과 상세)
- **뷰어**: 화면 위쪽 검정 알약 바(제목 · 모드 · 시간 · 버튼), 왼쪽 지문 / 오른쪽 문항 2단, 떠 있는 마킹 패널
- **빈 상태**: 가운데 회색 13px 한 줄 ("조건에 맞는 콘텐츠가 없어요.")
- **문구**: 해요체, 짧게 ("새로 고침 했어요", "리뷰를 남겼어요. 감사합니다!")

## 7. 통합 앱 적용 원칙

1. 헤더 · 탭바 · 좌우 30px 여백 · 1px 회색 박스는 서랍장 · 타이머 골격을 그대로 씀
2. 화면 안 전환(문항/성적, 스크랩/오답 정리 등)은 20px/800 큰 텍스트 토글
3. 버튼은 회색 · 검정 알약형, 모달 하단만 68px 전폭 분할 버튼
4. 과목은 as-is 과목 색(점 · 연한 채움)으로 표시
5. 홈 첫 화면은 콘텐츠 서랍장 1페이지(연간 표)와 같은 구성
